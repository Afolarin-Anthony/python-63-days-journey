## What I learnt
- repr() ---> Returns an unambiguous string representation of an object.
  
- isinstance() ---> Gets the exact class name as a string.
  
- dir() ---> List all attributes and methods available on an object.
  
- issubclass() ---> Checks class inheritance to see if one class derives from another class.
  
- type().__name__  ---> Gets the exact class name as a string.

## More researched
- hasattr() ---> Verfifies if an attribute exists on an object, returning a boolean.
- getattr() ---> Fetches an attribute's value dynamically using its string name allowing one to access variables or methods dynamically.
- callable() ---> Checks if an object can be called like function (returns True for functions, methods, and classes).
